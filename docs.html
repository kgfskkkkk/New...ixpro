Quick start

Pairing links your real WhatsApp number to a running bot session. No QR scanner needed — you type in a short code instead.

1. Open the pair page

Go to /pair and enter your number in international format, e.g. 94771234567 (no +, no spaces).

2. Get a pairing code

Agree to the terms and tap Submit. A one-time code appears — tap it to copy.

3. Link the device

On your phone: WhatsApp → Settings → Linked Devices → Link a Device → Link with phone number instead, then enter the code.

Already paired and need a new session? Use the Re-Pair button that appears on the pair page for that number.

Command prefix

Every command starts with a prefix — . by default. Send it in any chat the bot can see (including your own message thread).

.menu            → list all commands
.help <command>  → usage for a specific command
.prefix .        → change the prefix (owner only)

FAQ

Does pairing create a separate WhatsApp account?

No — pairing links the bot as an additional linked device on your existing WhatsApp number, the same way WhatsApp Web works.

Can I run more than one number on the same bot?

Yes, the bot supports multiple paired numbers at once — each keeps its own session.

My number says "already paired" — what now?

Use the Re-Pair button on the pair page to generate a fresh code for that number.

How do I remove the bot from my number?

Go to WhatsApp → Settings → Linked Devices, select the bot's session, and tap Log Out.
